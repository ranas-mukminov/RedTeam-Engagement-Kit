# Security Policy

## Scope

This repository is documentation for authorised engagements only. It is not
a product, not a service, and not a target. Nothing in it should be run
against a live system.

## Reporting a problem in this repository

If you find an error in a template, a misleading statement, or a process
gap, open an issue describing the template and the line concerned. Do not
include real client names, real system addresses, credentials, or any data
from a real engagement.

## Responsible disclosure

Findings from a real engagement are disclosed only to the system owner,
only through the channel agreed in the signed scope, and only within the
window agreed in that scope. Public write-ups, if any, use redacted,
owner-approved material only, and never before the owner has had the agreed
remediation window.

## Out of scope

Unsolicited testing of this repository's author, of any system named in an
example, or of any third party is not authorised by this repository and
must not be presented as authorised by it. Example names, addresses and
identifiers in the templates are fictional placeholders.
