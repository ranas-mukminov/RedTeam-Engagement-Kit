# Pre-Engagement Checklist

All items must be "yes" before testing starts. A single "no" blocks the
engagement until it is resolved in writing.

## Authorisation

- [ ] Signed scope document received (see `templates/scope-authorisation.md`)
- [ ] Authorising person's authority over the targets confirmed
- [ ] Window, timezone, and blackout periods confirmed with the owner
- [ ] Out-of-scope list reviewed with the whole test team

## Targets and accounts

- [ ] Target list matches the signed scope exactly — no additions
- [ ] Test accounts confirmed working; no real user accounts in use
- [ ] No production credentials held by the test team
- [ ] Rollback / restore procedure confirmed for any state-changing test

## Communication

- [ ] Owner escalation contact tested (a message was answered)
- [ ] Emergency stop contact and procedure agreed
- [ ] Daily or milestone reporting rhythm agreed
- [ ] Incident procedure agreed: who is told, how fast, in what form

## Tooling and data

- [ ] Tools and their versions recorded for the report
- [ ] Evidence storage location agreed; encryption at rest confirmed
- [ ] Retention period and deletion date agreed
- [ ] Team members briefed on stop conditions and on the "not in scope,
      not tested" rule

## Go / no-go

- Date and time: [to be filled in]
- If any item is unchecked, the decision is no-go, and the reason is
  recorded here: [to be filled in]
